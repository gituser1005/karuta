# 問題データと学習状態

## ファイルと読み込み

`data/capitals.js` が問題データの唯一の管理元です。JSON互換のオブジェクトを `window.KarutaDeck` に代入するだけで、出題・採点・音声の処理は含みません。

`capital-karuta.html` はこのファイルを通常のscriptとして読み込んだ後に `capital-karuta.js` を実行します。fetchやES Modulesは使わないため、GitHub Pagesのサブディレクトリー配信とHTMLの直接起動（file://）を維持できます。非同期読み込み後の自動発話も追加していません。

## データ構造

```json
{
  "schemaVersion": 1,
  "id": "world-capitals-ja",
  "title": "世界の首都",
  "questions": [
    {
      "id": "capital-au",
      "question": "オーストラリアの首都は",
      "answer": "キャンベラ"
    }
  ]
}
```

上記は構造の抜粋です。実データは既存の20問を同じ順序で保持しています。

- `schemaVersion`：現在は1。未対応の版は起動時にエラーにします。
- デッキの `id`：問題集の固定IDです。
- `title`：問題集の表示名です。現在のかるたの画面タイトルは変更していません。
- 各問の `id`：並び順や表示名に依存しない固定IDです。首都データでは `capital-au` などのIDを使います。並べ替えや表記修正で変更・再生成しないでください。削除した問題のIDを別の問題に再利用しないでください。
- `question`：答えを含まない問題文です。文字表示・初期の読み上げ・将来の暗記カード表面に使用できます。
- `answer`：札と暗記カード裏面に使用できる答えです。
- 任意の `speech.question` / `speech.answer`：表示と発音を分けたい場合だけ指定します。未指定なら `question` / `answer` をそのまま読みます。現在の20問は上書きを使わず、従来の発話文字列を維持しています。

読み上げの上書き例：

```json
{
  "id": "example-term",
  "question": "用語の意味は",
  "answer": "表示上の答え",
  "speech": {
    "answer": "こえでよむこたえ"
  }
}
```

これは形式の例で、首都20問には追加していません。かるたの日本語音声選択・速度・開始停止処理は `capital-karuta.js` の既存実装を維持しています。英語音声の選択などは今回の対象外です。

## 学習状態

`capital-karuta.js` の `learningState` は `Map<questionId, state>` です。

```js
learningState.get('capital-au');
// { streak: 0, attempts: 0, due: 0, mastered: false }
```

ゲーム内の項目は `{ id, data, state }` を持ち、`data` は変更不可の問題定義、`state` はMap内の状態への参照です。出題・卒業判定・札補充は状態側だけを更新します。リセットではMapを作り直します。

既存実装にはlocalStorage等への保存がなかったため、移行すべき保存データはありません。現在は別の `learning.js` が暗記カードの長期評価・復習予定とかるた累計統計をlocalStorageへ保存します。`due` はこのかるたの出題回数を基準にした復習位置で、日時ではありません。

## 暗記カードとの共用

- 同じデータファイルを読み込み、問題IDをそのまま利用してください。国名・首都の対応を別ファイルへ複製しないでください。
- 問題データに正答回数や復習日時を書き込まないでください。保存する場合はデッキID・問題IDで紐づけ、保存形式の版を管理してください。
- かるたの連続先取りや `due` と、暗記カードの評価・復習日時は意味が異なります。機能ごとの状態を区別し、同じフィールドで上書きしないでください。
- 9枚表示・5秒・2回連続先取り・日本語向けの画面文言はかるた側のルールです。問題データに持ち込まないでください。データ検証はかるた用に10問以上を要求しますが、暗記カードにその制限を課す必要はありません。
- 音声ヘルパーの大規模な共通化は行っていません。今回追加した読み上げテキストの形式は再利用できますが、再生制御を共通化する際はSafariの停止・再生間隔とユーザー操作の条件を保ってください。

## 検証

```powershell
node --test tests/question-data.test.cjs
```

依存パッケージの追加は不要です。テストはGit履歴内の公開済み実装 `326969f` の札数だけを9枚に変更した比較基準と同じ乱数・時計・音声イベントで比較し、出題、9枚の札、補充、ダミー、先取り、卒業、終了、発話文字列・時刻・順序が一致することを確認します。意図的に仕様変更する場合は比較基準も見直してください。音声APIはモックであり、Safari実機での音声品質を保証するものではありません。

現在の暗記カード実装と保存形式は [暗記カードの設計](flashcards.md) を参照してください。かるたの `learningState` Mapはセッション用で、長期の評価・復習予定とは別管理です。
