# 暗記カードと共通学習状態

## 構成

- `data/capitals.js`：かるたと暗記カードで共用する問題定義。今回変更・複製していない。
- `flashcards.html` / `flashcards.css` / `flashcards.js`：カード表示・反転・評価・結果・取り消し。
- `learning.js`：DOMに依存しない復習計算、対象抽出、スワイプ方向判定、バージョン付き保存処理。
- `flashcard-audio.js`：答えの手動読み上げ。任意の `speech.answer` を優先する。
- `capital-karuta.js`：従来のゲーム処理・音声処理を維持し、共通記録から練習候補を選ぶ。

## 操作とセッション

かるたの「暗記カードへ」から切り替える。問題文を見てからカードをタップすると答えを表示し、再タップで表面へ戻る。一度答えを表示するまでは評価できない。一度確認した後は表裏どちらでも自己評価できる。

左＝忘れた、上＝迷った、右＝覚えていた。ドラッグはPointer Eventsを使用し、マウスとタッチを同じ方向判定で扱う。評価可能なカード上だけ `touch-action:none` にしてブラウザーのスクロールとの競合を避ける。方向は主軸が他軸の1.35倍以上のときに決まり、距離はカード幅の24%（65〜100px）以上で確定する。短距離、下向き、45度付近の斜め操作は取り消す。3つの評価ボタンはスワイプと同じ処理を使う。

評価が保存できた後でカードを飛ばし、次のカードを表面から表示する。表示切り替え時は反転途中の答えが見えないようにする。動きを減らすOS設定では反転・飛び出しを省略する。

1セッションは復習予定到来分と未学習の最大20枚。復習予定到来分を日時の古い順に、その後に未学習を表示する。未来の予定は対象外。今回「忘れた」カードを同じセッションに自動追加はせず、予定が到来した次のセッションで再出題する。終了後は枚数別の結果を表示し、対象0枚なら「今日の復習は完了しています」と案内する。

セッションの途中位置自体は保存しない。再読み込み時は保存済み評価を使って復習対象を再計算する。

## 復習計算

`KarutaStudy.schedule(previous, rating, now)` をUIとは独立した純粋関数として用意している。

| 評価 | 次の間隔 |
| --- | --- |
| 忘れた (`forgot`) | 10分 |
| 迷った (`hesitant`) | 前の間隔の1/2。ただし最短1時間、最長1日 |
| 覚えていた (`remembered`) | 前の間隔の2倍。ただし最短1日、最長365日 |

未学習の初回はそれぞれ10分・1時間・1日。`nextReviewAt = now + intervalMs`。サーバーではなく端末の時計を使う簡易方式であり、FSRSは導入していない。FSRS等へ変更する際は、この関数と保存形式の移行を独立して差し替える。

## 保存データ

localStorageキーは `karuta.learning.v1`。問題集IDと問題IDをキーにする。

```js
{
  version: 1,
  decks: {
    "world-capitals-ja": {
      "capital-au": {
        flashcard: {
          lastRating: "remembered",
          lastReviewedAt: 1794614400000, // ミリ秒のUnix時刻
          nextReviewAt: 1794700800000,
          intervalMs: 86400000,
          history: [{
            id: "評価イベントの一意ID",
            rating: "remembered",
            reviewedAt: 1794614400000,
            nextReviewAt: 1794700800000,
            intervalMs: 86400000
          }]
        },
        karuta: {
          attempts: 2, early: 2, late: 0, wrong: 0,
          graduations: 1, lastPlayedAt: 1794614400000
        }
      }
    }
  }
}
```

`flashcard` と `karuta` は必要なときだけ存在する。問題データへ履歴や評価を書き戻さない。既存版には保存機能がなかったため初期移行は不要。未対応バージョンや壊れたデータは上書きせず、その画面内だけの一時練習へ切り替えて通知する。

localStorageが利用できない場合も一時練習は可能だが、保存されない旨を画面に表示する。容量不足等で書き込みに失敗した評価は確定せず、カードを進めない。データは端末・ブラウザー・配信元ごとで、クラウド同期はない。file://では別HTML間の共有がブラウザーに依存するため、HTTPサーバーまたは公開サイトで利用する。

## 戻る

評価時に、その問題の評価前の `flashcard` 全体と評価イベントIDをセッション内のスタックへ保持する。「戻る」は評価前の間隔、予定日時、評価履歴をすべて復元し、元のカード・表裏の状態へ戻す。最初の評価を取り消した場合は未学習に戻る。結果画面からも取り消せる。

取り消しは `flashcard` だけを戻し、他の画面で追加された `karuta` 記録は残す。別タブで同じ問題へ新しい評価が付いた場合は、最新記録の上書きを防ぐため取り消しを拒否して案内する。戻るスタックは再読み込みで破棄する。

## かるた連携

通常は未学習 → 忘れた → 迷った → 復習予定が到来した覚えていた、の順で初期候補を優先する。未来の「覚えていた」は通常出題から除外する。問題内のランダム出題・復習までの出題回数・2回連続先取り・毎問シャッフルは従来のルールを保つ。

候補が9問未満でも、候補以外の問題をダミーとして補充して9枚を保つ。卒業済み・未来の予定の問題もダミーには使用できる。卒業判定の分母はその回の練習候補数とする。候補0問ではゲームを自動開始せず案内を表示し、「全問で練習する」を選べば自由に遊べる。

かるたのリセットで消すのはセッション内の進行だけ。長期評価は消さない。かるたの結果は `karuta` 統計へ保存するが、「覚えていた」への自動変換や長期復習間隔の延長は行わない。卒業しただけでは暗記カードの復習から外れない。

## 音声

暗記カードは裏面のボタンを押したときだけ答えを読み上げる。自動再生しない。表面に戻す、評価、取り消し、次カード、ページ離脱・非表示の際に停止する。非対応・再生失敗でも評価は続けられる。

既存かるたの読み上げタイミングを変えないため、既存の音声関数を大規模に抽出していない。手動プレイヤーは同じWeb Speech API方式、日本語音声選択、アイドル時の不要なcancel回避、置き換え時80msの間隔、古いイベントの無視を踏襲する。任意の読み上げテキストも共用する。Safari実機での音質・開始時刻の再確認は必要。

## 検証方法

```powershell
node --test tests/learning.test.cjs tests/question-data.test.cjs
node tests/browser-flashcards.cjs
```

前者はスケジュール、保存、取り消し、かるたの全件クリアと既存音声との比較を実行する。後者はNode.js 22以上とChrome、ローカルHTTPサーバーを使用する。既定URLは `http://127.0.0.1:8082/karuta/`。`KARUTA_TEST_URL`、`CHROME_PATH` で変更できる。隔離したChromeプロファイルを使い、実際の利用者の履歴へ触れない。音声APIはモックで発話内容・停止を検証する。

GitHub Pagesと同じ `/karuta/` 配下で相対リンクとファイル配信を検証する。公開先そのものの確認は、ユーザー承認後にpush・デプロイしてから行う。

「復習対象を確認する」は予定を再計算します。対象0枚の場合はその旨を表示し、直前の結果と取り消し履歴を維持します。対象がある場合だけ新しいセッションを開始します。
