# 首都かるた

世界20か国の首都を覚える、ブラウザーで遊べる1人用かるたゲームです。画面は `capital-karuta.html`、スタイルは `capital-karuta.css`、ゲームの処理は `capital-karuta.js` に分かれています。インストールやビルドは不要です。

## ルール

- 「スタート」で開始し、国名の読み札に対応する首都の札を選びます。常に12枚を表示します。毎問の開始時に札の並びをシャッフルします。
- 問題開始から5秒未満に、お手つきなしで正解すると「先取り成功」です。5秒後から首都名を文字で表示します。
- お手つき後も回答できますが、その問題は先取り失敗になります。時間切れによる自動終了はありません。
- 同じ首都の出題で2回連続して先取りに成功すると卒業します。先取り失敗で、その首都の連続成功回数は0に戻ります。
- 回答済みの首都は復習として再出題されます。卒業した札は未登場の札と交換し、未登場の札がなくなると卒業済みのダミー札で補充します。
- 全20か国の卒業でクリアです。出題数、先取り成功・失敗、お手つきの回数を表示します。
- 文字速度は0.4秒／文字で固定です。速度調整欄はありません。首都名の表示開始は常に5秒後です。
- 「最初から」で進行と成績をリセットします。進行状況の保存機能はありません。

## 起動方法

`index.html` または `capital-karuta.html` をブラウザーで開いてください。`index.html` はゲームへの案内ページです。`capital-karuta.html`・`capital-karuta.css`・`capital-karuta.js` は同じフォルダーに置いてください。外部ライブラリー、サーバー、音声読み上げは使用していません。

## GitHub Pages

公開設定は Settings → Pages → Deploy from a branch → `main` → `/(root)` を使用します。公開後はサイトのトップページからゲームを開けます。

## ファイル

- `capital-karuta.html`：画面構造
- `capital-karuta.css`：スタイル、レスポンシブ表示、ダークモード
- `capital-karuta.js`：ゲームデータ、出題・判定・進行処理
- `index.html`：公開サイトの入口
- `AGENTS.md`：仕様と開発時の注意事項

スマートフォンでは3列の札を表示し、読みやすい文字サイズとタップ領域を確保しています。画面の切り欠きに応じた余白、キーボードのフォーカス表示、OS設定に応じたダークモードと動きを抑える設定に対応しています。
