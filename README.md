# 首都かるた

世界20か国の首都を覚える、ブラウザーで遊べる1人用かるたゲームです。画面は `capital-karuta.html`、スタイルは `capital-karuta.css`、ゲームの処理は `capital-karuta.js` に分かれています。インストールやビルドは不要です。

## ルール

- 「スタート」で開始し、国名の読み札に対応する首都の札を選びます。常に12枚を表示します。毎問の開始時に札の並びをシャッフルします。
- 問題開始から5秒未満に、お手つきなしで正解すると「先取り成功」です。5秒後から首都名を文字で表示します。
- お手つき後も回答できますが、その問題は先取り失敗になります。時間切れによる自動終了はありません。
- 同じ首都の出題で2回連続して先取りに成功すると卒業します。先取り失敗で、その首都の連続成功回数は0に戻ります。
- 回答済みの首都は復習として再出題されます。卒業した札は未登場の札と交換し、未登場の札がなくなると卒業済みのダミー札で補充します。
- 全20か国の卒業でクリアです。出題数、先取り成功・失敗、お手つきの回数を表示します。
- 文字速度は0.4秒／文字で固定です。速度調整欄はありません。首都名の表示開始は常に5秒後です。
- 「最初から」で進行と成績をリセットします。進行状況の保存機能はありません。

## 音あり／音なし

- 初期状態は音なしです。「読み上げ」で切り替えます。設定はリセット時も維持しますが、再読み込みでは音なしに戻ります。
- 音ありでは問題開始時に「国名＋の首都は」、開始5秒後に首都名を読み上げます。札を選ぶと、選んだ首都名を読み上げます。
- 文字は従来どおり0.4秒／文字で表示し、先取り判定は音声と独立した開始5秒未満の基準を維持します。音声の開始時刻や発音は端末に依存します。
- 正解後は最低950ミリ秒、音ありでは札の読み上げ終了まで待って次問へ進みます。発話完了が通知されない場合も6秒で次問へ進みます。
- 音なしへの変更、リセット、次問への移行、画面から離れたときは発話を中断します。
- 非対応ブラウザーや音声エラー時も音なしで遊べます。

## 起動方法

`index.html` または `capital-karuta.html` をブラウザーで開いてください。`index.html` はゲームへの案内ページです。`capital-karuta.html`・`capital-karuta.css`・`capital-karuta.js` は同じフォルダーに置いてください。外部ライブラリーやサーバーは不要です。音ありを選ぶと、ブラウザーのWeb Speech APIで読み上げます。

## GitHub Pages

公開設定は Settings → Pages → Deploy from a branch → `main` → `/(root)` を使用します。公開後はサイトのトップページからゲームを開けます。

## ファイル

- `capital-karuta.html`：画面構造
- `capital-karuta.css`：スタイル、レスポンシブ表示、ダークモード
- `capital-karuta.js`：ゲームデータ、出題・判定・進行処理
- `index.html`：公開サイトの入口
- `AGENTS.md`：仕様と開発時の注意事項

スマートフォンでは3列の札を表示し、読みやすい文字サイズとタップ領域を確保しています。画面の切り欠きに応じた余白、キーボードのフォーカス表示、OS設定に応じたダークモードと動きを抑える設定に対応しています。

## 読み上げテスト

`speech-test.html` をブラウザーで開きます。通常ゲームとは独立したテスト画面です。

- 「文章を読み上げる」で「オーストラリアの首都はキャンベラです」を読み上げます。
- 選択肢は「キャンベラ」の1枚だけで、選ぶと「キャンベラ」と読み上げます。
- 再タップでは前の音声を中断して新しい読み上げを開始します。「停止」でも中断できます。
- Web Speech APIを使用し、日本語音声を優先します。速度・高さは標準値です。
- 自動再生はしません。Safariではボタンや札をタップして試してください。音声と開始までの時間は端末に依存します。
- `speech-test.html`・`speech-test.js`・`speech-test.css`・`capital-karuta.css` を同じフォルダーに置いてください。
- 通常ゲームとは別のURLで動作します。iPhone/MacのSafariで、文章・札・連打による中断・停止を実機確認してください。

### Safariで音が出ない場合

消音モードを解除して音量を確認し、「音なし」→「音あり」で試してください。発話の開始イベントを3秒以内に確認できない場合は案内を表示します。再生していない音声への不要な停止は避け、発話の置き換え時だけ停止後80ミリ秒以上空けています。この対策でSafari実機の動作が保証されるわけではありません。
